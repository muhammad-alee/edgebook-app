# Edgebook (hosted build)

This repo holds only the compiled, static output of [Edgebook](https://github.com/muhammad-alee/edgebook),
a private client-side trading journal (no backend — all data stays in your browser's `localStorage`).

It exists solely so GitHub Pages can serve the app at a public URL. There's no source code here;
the app is built from the private source repo and pushed here on each release.

Live: https://muhammad-alee.github.io/edgebook-app/
